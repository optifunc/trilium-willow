# Is Willow a fit for your notes?

## Already using Trilium

Willow adds another way to work inside your existing notes: a compact hierarchy
that lays itself out, supports keyboard restructuring, folds detail and holds
checkboxes. Try a brainstorm, a reference page you reopen often, or a packing list.
Each map lives in one Trilium note and uses your existing Trilium setup.

You may already have what you need in Trilium's native Mind Map, which includes
keyboard creation, formatting and image export. [Compare the same example](comparison.md),
then [install Willow](../README.md#install-and-make-a-map) if its presentation suits you.

## Coming from FreeMind

Willow grew out of its author's move from FreeMind. In their own setup they ran
into macOS application problems and Windows rendering problems, and wanted browser
access. That is their experience, not a claim about every current FreeMind installation.

The familiar idea is a hierarchy you can create, move and fold quickly. Willow
adds that working style to Trilium, including Trilium's desktop/browser access,
sync and protected notes. You need a Trilium instance first.

**FreeMind `.mm` import is not available yet.** Start with a small new map to judge
the workflow; do not expect an existing FreeMind file to open in Willow. Outline
clipboard support is useful for text, but it is not a FreeMind migration feature.
Keep your original maps. [See the examples](examples.md) and [setup prerequisite](#new-to-trilium).

## New to Trilium

Willow is an add-on, so downloading its ZIP is not the first step. Install
[Trilium Notes](https://triliumnotes.org/) and create a knowledge base using the
[official setup guide](https://docs.triliumnotes.org/user-guide/setup).
A Trilium desktop app is a straightforward local starting point. Browser access
requires a running Trilium instance configured for it; Willow does not provide a
hosted account or its own sync service.

Once Trilium is ready, [import Willow and make your first map](../README.md#install-and-make-a-map).
You can use it for information you revisit as well as ideas you edit. Start with
one useful map, such as a home reference or a weekend packing list, and see whether
the compact view helps you recognize what you need.
